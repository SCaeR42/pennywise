> [!IMPORTANT]
> Документ актуализирован: май 2026. Проект находится в стадии активной разработки (MVP готов).

---

## 📋 Описание проекта

**PennyWise** — это кроссплатформенное веб-приложение для личного учёта финансов, построенное на современном стеке Vue 3. Приложение позволяет пользователям вести учёт доходов, расходов и переводов между счетами, а также анализировать финансовые данные через интерактивные
дашборды.

### Ключевые особенности

- **Приватность данных**: Все данные хранятся локально в браузере (localStorage)
- **Интуитивный интерфейс**: Современный дизайн на базе shadcn-vue
- **Аналитика в реальном времени**: Дашборд с графиками и статистикой
- **Тёмная тема**: Полная поддержка светлой/тёмной темы
- **Адаптивный дизайн**: Mobile-first подход

## 🚀 Этапы реализации (выполненные)

### Этап 1: Базовая структура ✅

- Инициализация проекта через Vite
- Настройка Tailwind CSS и shadcn-vue
- Настройка маршрутизации с защитой маршрутов

### Этап 2: Промо-страница ✅

- Создание Index.vue с секциями: Hero, Features, Pricing, FAQ, Footer
- Использование shadcn-компонентов

### Этап 3: Авторизация ✅

- Pinia Store `useAuthStore` с mock-данными
- Middleware через `router.beforeEach`
- Регистрация и вход пользователей

### Этап 4: Транзакции ✅

- CRUD операции для транзакций
- Фильтрация и отображение данных
- Форма создания/редактирования

### Этап 5: CRUD справочников ✅

- Категории, счета, теги
- Полный цикл создания/обновления/удаления

### Этап 6: Дашборд и аналитика ✅

- Интерактивные графики (BarChart, PieChart, TrendChart)
- Карточки статистики
- Фильтры по периоду и счетам

### Этап 7: Настройки ✅

- Переключение темы (light/dark/system)
- Настройка количества строк в списках

## 📊 План презентации проекта

### 1. Цели проекта

| **Аспект**          | **Описание**                                                                    |
|---------------------|---------------------------------------------------------------------------------|
| **Основная задача** | Создание удобного, кроссплатформенного инструмента для контроля личных финансов |
| **Приватность**     | Локальное хранение данных без отправки на сервер                                |
| **Скорость**        | Быстрая работа за счёт клиентского хранения                                     |
| **Интуитивность**   | Минимум кликов для ввода транзакций                                             |

### 2. Реализованный функционал

| **Модуль**         | **Функции**                                   | **Статус** |
|--------------------|-----------------------------------------------|------------|
| **Авторизация**    | Регистрация, вход, выход                      | ✅          |
| **Транзакции**     | CRUD, фильтрация, типы (доход/расход/перевод) | ✅          |
| **Справочники**    | Категории, счета, теги                        | ✅          |
| **Дашборд**        | Графики, статистика, топ-транзакции           | ✅          |
| **Настройки**      | Тема, параметры отображения                   | ✅          |
| **Промо-страница** | Landing page с ценовыми предложениями         | ✅          |

### 3. Техническая архитектура

```
┌─────────────────────────────────────────────────────────────┐
│                        Клиент (Vue SPA)                      │
├─────────────────────────────────────────────────────────────┤
│  Router → Guards → Layout → Pages → Components               │
├─────────────────────────────────────────────────────────────┤
│  Pinia Stores:                                               │
│  • useAuthStore   — пользователь и сессия                   │
│  • useDataStore   — транзакции, категории, счета, теги      │
│  • useThemeStore  — светлая/тёмная тема                      │
├─────────────────────────────────────────────────────────────┤
│  Storage Layer:                                              │
│  • localStorage (через lib/storage.ts)                       │
│  • Демо-данные (lib/demoData.ts)                             │
└─────────────────────────────────────────────────────────────┘
```

### 4. Ключевые решения

| **Задача**           | **Решение**                   | **Обоснование**                       |
|----------------------|-------------------------------|---------------------------------------|
| **State Management** | Pinia setup-функции           | Современный паттерн, типобезопасность |
| **Хранение данных**  | localStorage                  | Простота, приватность, нет backend    |
| **UI Kit**           | shadcn-vue                    | Консистентный дизайн, кастомизация    |
| **Валидация**        | Планируется VeeValidate + Zod | Готово в dependencies                 |
| **Тема**             | CSS-классы + watcher          | Простая и надёжная реализация         |

### 5. Статистика кода

| **Показатель**  | **Значение**                    |
|-----------------|---------------------------------|
| **Строк кода**  | ~5000+ (Vue SFC)                |
| **Компонентов** | 50+ UI + 15+ бизнес-компонентов |
| **Страниц**     | 12 основных страниц             |
| **Stores**      | 3 (auth, data, theme)           |
| **TypeScript**  | 100% типизация                  |

### 6. Демонстрация (скриншоты/видео)

1. **Промо-страница** — Index.vue с Hero-секцией
2. **Дашборд** — аналитика с графиками
3. **Транзакции** — список с фильтрами
4. **Форма транзакции** — создание/редактирование
5. **Настройки** — переключение темы

### 7. Планы развития

| **Приоритет** | **Задача**            | **Ожидаемый результат**                |
|---------------|-----------------------|----------------------------------------|
| 🔴 Высокий    | Supabase backend      | Синхронизация между устройствами       |
| 🟡 Средний    | VeeValidate + Zod     | Валидация форм                         |
| 🟢 Низкий     | PWA (vite-plugin-pwa) | Работа офлайн, установка на устройство |
| 🟢 Низкий     | Банковские API        | Автоматический импорт транзакций       |
